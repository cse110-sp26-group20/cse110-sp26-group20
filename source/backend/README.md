# backend

## Commands

| Command                | Action                                  |
| :--------------------- | :-------------------------------------- |
| `npm install`          | Install dependencies                    |
| `npm run dev`          | Start local dev server                  |
| `npm run build`        | Build production server                 |
| `npm run start`        | Start production server                 |
| `npm run lint`         | Run ESLint on the backend code          |
| `npm run lint:fix`     | Run ESLint and apply safe fixes         |
| `npm run format`       | Format the backend code with Prettier   |
| `npm run format:check` | Verify formatting without writing files |
| `npm run test`         | Run backend tests                       |

## Setup

Install dependencies from the **repository root** (required for npm workspaces and shared tooling):

```bash
cd ../..   # repo root
npm install
```

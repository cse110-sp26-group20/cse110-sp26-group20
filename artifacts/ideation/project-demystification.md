# Unified Idea of Project

## Description

A meme generator web app that allows users to create memes using meme building tools and templates\. It also allows users to directly generate memes with AI using inputted images\.

## Personas

Teen to young adult internet users looking for create memes or make jokes\. Are generally up to date with pop culture, news, and social media\.

## Primary Features

- Meme building tool/playground
- AI meme generator feature
- Meme templates

## Must Have

- Mobile compatibility and emphasis
- Fast generation
- Organized and easy to use UI

## Must Avoid

- Complex features
- Unorganized UI
- Slowness

## Risks

- Deciding on models to use for AI

## Rabbit Holes

- Feature creep
- Finding the perfect UI design and themeing

# Potential Features

## Basic Functionality
- Selection of template
- Text editor
- Image tools
- Ability to share/export
  - Potentially in different image formats?

## More Advanced
- Login/saving across sessions
- Saved memes library or history tab to see previously generated memes
- Trending tab to see what memes are currently trending to get ideas of what to generate
  - Additionally a general explore tab where you can select specific communities
- Ability to generate videos, with video templates for current memes

## AI-Related
- Context-aware caption generation
- Generation of new template via prompting
- Regeneration upon dissatisfaction
- Ability to blur faces, filter/not use images with derogatory/offensive content

# User Stories
- As a 13-year old obsessed with science fiction, I would like to generate memes about my favorite characters from the books I read so I can share it with my friends.
- As a teacher of a freshman class in high school, in order to make learning more fun for my students I would like to generate memes about calculus for my class.
- As a young adult running a meme page on social media, I would like to be able to more easily generate bespoke memes about current pop culture, in order to make my page more relevant and engaging to my followers.
- As a teenager, my friends and I share memes in our group chat with each other all the time and I would like to be able to create memes in our group chat itself quickly and on the fly.
- As someone who has difficulties reading, I would like the user interface to be as simple as possible with very little clutter on the screen, so that I can easily figure out how to use the app quickly and effectively.
